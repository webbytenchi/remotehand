# RemoteHand v1.3.1 — Acceptance Record

Date: 2026-10-01

## Result

RemoteHand v1.3.1 extends the existing Plugin API v1 platform with generic encrypted Vault blob storage, Vault lock-state events for plugin panels, and serialized plugin runtime request/response handling.

## Accepted changes

- Generic encrypted Vault blob storage for plugin-owned binary data
- Caller-scoped `vault.blobs.read` and `vault.blobs.write` permissions
- Chunked blob begin/write/commit/abort/info/read/delete host operations
- Opaque HMAC-derived physical blob filenames
- XChaCha20-Poly1305 authenticated 1 MiB blob chunks
- Vault lock aborts in-progress uploads and stale upload staging is cleaned
- Vault status events are forwarded to plugin panels for immediate redaction
- Full plugin runtime request/response lifetimes are serialized so nested host API responses cannot be overtaken by concurrent panel calls

## Compatibility

- RemoteHand Plugin API remains v1
- Existing API-v1 plugins require no migration
- Existing structured Vault secret/document behavior remains available
- Vault blob storage is additive and permission-gated

## Release dependency

RemoteHand Notes v0.1.1 uses these generic v1.3.1 core capabilities for encrypted attachment storage and safe image-preview reads.

## Validation

The Vault blob and plugin-runtime changes were manually exercised with RemoteHand Notes during integration. Final RemoteHand v1.3.1 release validation must be performed from the exact intended release commit before the annotated tag is created.
